# 词加加 WordPlusPlus

一个手机号登录的背单词网站：每天 30 个新词 + 艾宾浩斯复习，支持自定义词库；管理员可维护全局释义修正。

## 功能

- 手机号 + 密码注册登录，每个账号独立保存数据
- 1800 个单词，每天 30 个新词
- 艾宾浩斯复习：第 1、2、4、7、15、30 天
- 随机乱序背词，答错循环复习直到全部答对
- 选择题 / 手打答案 / 自测三种模式
- 自定义词库：可新建、重命名、删除，单词可添加 / 编辑 / 删除
- 每人所有自定义词库总词数上限 10000 个（删除词会释放额度）
- 全局释义修正：管理员维护，对所有用户生效
- 修改密码：设置页直接改，管理员也在这里改成强密码
- 管理员用量页：数据库大小、注册人数 / 名额、每人词库数 / 单词数；总用量占免费额度（默认 512 MB）的百分比，达到 70% 变黄、90% 变红
- 管理员可为每个账号保存备注（姓名 / 来源）
- 旧版添加的图片数据已全部清除，不再统计
- 注册名额可设为 0（不限）或任意数量，最多 999999
- 管理员由部署时的 `admin_phone.txt` 指定，不再自动给第一个注册者
- 注册页隐私说明：手机号仅用于登录和找回，不会公开

## 技术栈

- Python / Flask
- SQLite
- HTML / CSS / JavaScript

## 本地运行

```bash
pip install -r requirements.txt
python app.py
```

Windows 上如果 `python` 命令不可用，用 `py app.py`。默认端口：8002。

本地测试管理员时，可以用环境变量代替 `admin_phone.txt`：

```powershell
$env:ADMIN_PHONE='你的11位手机号'
py app.py
```

管理员注册密码要求：至少 12 位，包含大写字母、小写字母、数字和符号；不要用手机号、生日、姓名拼音，也不要和别的网站密码相同。
